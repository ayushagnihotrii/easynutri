EasyNutri — Clinical Architecture & Live Features

1. Full-Stack Multi-Module

Pure Java 17 domain rules (:domain) with 0 framework coupling, Spring Boot 4.1.2 MVC/REST server (:server), and Android Client (:android).

2. Clinical Standards

ICMR-NIN Indian Food Composition Tables (IFCT 2017) and USDA FoodData Central with micronutrient calculations (Iron, Calcium, Fiber).

3. Zero-Waste Smart Pantry

Pure Java scoring engine matching available stock against verified recipes with dynamic expiration tracking to prevent food waste.

4. Sensitive-User Protection

Full-stack eating-disorder safeguard masking numerical calories and weight deficit terminology across views, charts, and API responses.
